## 旧格式错误的补充诊断

使用首轮旧提示词，对 PHP 倒序、材料不足、铁路重叠各追加 2 次，共 6 次。解析后的原始结构均通过生产校验，最长 reason 为 490 字符。未复现 `invalid_response`，不能断言此前错误来自超过 500 字符。最终提示词要求理由尽量不超过 200 字符，仍保留原有 500 字符硬限制。

## 复现与限制

按根 README 加载模型配置后运行：

```sh
python scripts/evaluate_content_deduplication.py \
  --cases evals/content_deduplication/cases-v2.json \
  --php-evidence-dir data/investigations/2026-10-22-content-dedup \
  --output data/content-dedup-evaluations/replay-v2.json \
  --repeats 3 --max-requests 60 --max-retries 0 --budget-usd 0.10
```

正文目录是本地材料，未提交；缺少这些正文时，默认 PHP 仅含摘要的实验标为非权威，不能与本次正文回归混报。其余合成案例无需该目录即可复现。`--cases cases.json` 只切换旧案例；要复现首轮指令，还需在临时实验副本中使用归档的 `system-v1.txt`，不能将当前指令跑旧案例称为首轮复现。

固定 SHA-256（文件／指令的原始 UTF-8 字节）：

- V1 案例：`d54609af38f7fc5c535a467bee6184615e7598863be8b9525917d88f49354453`
- V2 案例：`25bfaa646e0ee4cb5dce993eb78607e81d44b96cd2d7a96c9f2d7b99a5914056`
- V1 指令：`8bc4378f6f199fca0cba32ebcf45bf1d741e57be4f254c0b3e63edff00172503`
- V2 指令：`73b1e78f4c85da430868b2de8d96ad2636f77cc0c18ac4aabae2d06d78aac9b4`

运行器 JSON 中的 digest 是规范化 JSON 编码后的 SHA-256，与这里的原始字节 hash 定义不同。统计导出保留两种定义。供应商调用可能随机变化；同一案例重复 6 次不是 6 个独立样本。短且清晰的合成案例也不能代表真实长文章，当前结果不提供日常准确率估计。

离线完整测试：`pytest -q`，**1606 passed**。测试不访问真实模型；它们验证任意位置引用、拒绝循环／链、整批失败时保留、补选替换、栏目边界和最终历史等程序行为。
