# 逐条评阅要点

先读每条的“要讲清什么”，再看“容易写错什么”。这里列出的是材料依据和观察重点，不是要求逐项复述的标准答案。可选例子不必全写，未采用的评论也不必提及。

评阅时以模型实际收到的材料为准。所有要点依据保存快照整理，不代表对现实世界现状的独立核实；后续若发现要点有误，应修改要点，而不是要求模型迎合它。

案例输入见 [`cases.json`](./cases.json)，其中 `id` 与下列 HN ID 对应。

## Gemini 4 Argon

HN ID：`49913571` · 产品与服务介绍

**要讲清什么**

- 交代这是 Google 宣布的 Gemini 4 Argon，主要面向长期编程、企业知识工作和网络防御；当时先向可信防御者及测试者开放。
- 保留能说明实际用途的具体例子，例如 C/C++ 转 Rust、内存优化或长任务能力，不必罗列全部榜单。
- 若涉及价格或性能，说明是发布方给出的介绍性价格和内部/指定评测结果；若采用评论中的质疑，注明这是用户反馈。

**容易写错什么**

- 把宣布和分阶段开放写成已向所有 API 用户或订阅者普遍提供。
- 把正在迁移、仍需审查的代码工程写成全部完成并已投入生产。
- 把评论中 Gemini 3.8 Flash 的使用故事当作 Argon 的实测，或把推出时优惠价写成永久价格。

## America.gov

HN ID：`49893509` · 产品与服务介绍

**要讲清什么**

- 说明 America.gov 把分散的政府信息集中到 AI 问答入口，页面称回答只来自官方政府来源。
- 用一两项具体场景说明用途，例如寻找政府服务、岗位或护照相关信息；分清页面预览与已经可办理的业务。
- 若采用评论补充，可提及有人看好减少办事信息障碍，也有人担心隐私或功能实现；保留评论观点的归属。

**容易写错什么**

- 根据演示截图就断定所有业务都已可直接办理，尤其是护照申请、上传简历等功能。
- 把网站的免费、无广告、隐私保护宣传写成独立验证过的安全保证。
- 把评论引用的技术合作方、个人体验或未来功能推测写成正文已证实的完整实现。

## Web Search API

HN ID：`49963171` · 产品与服务介绍

**要讲清什么**

- 说明这是 Cloudflare 经 AI Gateway 提供的 beta 网页搜索 API，面向 AI 代理及应用，接入 Ceramic.ai、Exa、Linkup 三家提供商。
- 保留实际接入或费用机制之一：REST/Worker 调用、网关日志、按提供商目录价扣网关额度且不额外加价，也可自带 key。
- 若采用评论中的限制信息，说明结果保存、再分发条款及数据保留声明受到质疑，避免把各提供商条款混为一谈。

**容易写错什么**

- 写成 Cloudflare 新建了自己的搜索引擎，或把 beta 写成正式稳定版。
- 把不额外加价写成免费；把零数据保留和用户可无限存储搜索结果混为一谈。
- 把评论引用的 Ceramic 条款套用到全部三家，或把 Exa 的数据保留争议直接裁定为已证实违规。

## How Delhi cut electricity loss from 50 to 5 percent

HN ID：`49892245` · 较长文章与具体解释

**要讲清什么**

- 说明德里长期改革使损失从 2002 年逾 50% 降到 2026 年约 5%–6%，其中包含技术损耗、偷电和收费问题。
- 保留具体工程做法及其作用，例如电容补偿降低线路电流、SCADA 监控、绝缘线路防偷电、换表提高计量准确性；选最能解释结果的几项即可。
- 交代改善还依赖组织问责、缴费便利、执法及社区参与，不能只用一句“靠新技术”概括。

**容易写错什么**

- 把全部商业与技术损失当作导线发热浪费，或把 50% 到 5% 写成停电率变化。
- 把改善归因于单一措施，例如 AI、私有化、智能电表或太阳能，忽略文章呈现的组合改革。
- 把德里的结果扩大为印度全国已达到相同水平，或把多年改革写成短期一次改造。

## Opus 5.5 agents discover two room-temperature magnetic semiconductor candidates

- 讲清两种候选的区别：一种是新设计，另一种是重新发现已有材料的潜在性质；化学式可按需要保留。
- 保留计算预测仍需实验验证的限制；若展开具体结果，说明新设计的制备难点，以及已有样品尚未直接测量带隙和自旋分选。

**容易写错什么**

- 把半导体写成超导体，或把“室温候选”写成已经制造并验证的存储器突破。
- 把两种都说成 AI 首次合成的新材料，或把预测的带隙和自旋窗口写成实验测得。
- 混淆已有材料曾测得高于室温的磁有序，与本次所预测的自旋分选性质已验证。

## Livenerf: Has Opus 5.5 been nerfed yet?

## September 2026: The world today, as seen by one Polish guy

HN ID：`49905487` · 较长文章与具体解释

**要讲清什么**

- 说明这是作者从波兰出发的时事分析，核心观点是长期用外部依赖替代储备和冗余，使多重冲击相互放大。

## Denmark data breach exposes 8.8M people's personal data

HN ID：`49962012` · 新闻与事实边界

**要讲清什么**

- 交代丹麦 CPR 人口登记资料遭未授权访问，原因是有人滥用一家丹麦企业原本合法的查询权限，涉及约 880 万登记人员的姓名、地址、CPR 编号等资料。
